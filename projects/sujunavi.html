Overview

문제와 해결

공공입찰 담당자가 공고 하나를 앞에 두고 던지는 질문은 세 가지입니다. 우리가 참가 자격이 되는가, 얼마를 써야 따는가, 몇 곳과 붙는가. 나라장터는 이 중 어느 것도 답해주지 않습니다. 담당자는 공고문 수십 페이지를 직접 읽고 감으로 가격을 정합니다.

수주나비는 누적 수집한 공고와 실제 개찰 결과를 근거로 이 세 질문에 답합니다. 참가자격 충족 여부를 원문 조항과 함께 표시하고, 유사 공고의 개찰 이력에서 예상 낙찰가와 경쟁 규모를 산출합니다. 추정치만 던지지 않고 어느 사례에서 나온 숫자인지 공고 번호까지 공개합니다. 판단은 사용자가 합니다.

가장 자주 놓치는 것은 정정공고입니다. 마감일과 자격 요건이 조용히 바뀌는데 담당자는 원본만 보고 준비합니다. 변경 확인을 별도 기능이 아니라 기본 흐름에 넣은 이유입니다.

기술 검증용 사이드 프로젝트가 아니라 요금제와 결제, 고객 지원을 갖춘 상용 서비스입니다. 무료 체험 이후 유료 구독으로 이어지는 전환 구조를 직접 설계하고 운영합니다.

만드는 방식 자체가 이 프로젝트의 결과물입니다. 기획과 설계, 구현, 검증, 배포, 업데이트까지 전 과정을 agentic AI 루프로 자동화했습니다. 사람이 각 단계를 넘겨주는 대신 에이전트가 스펙에서 코드로, 코드에서 테스트로, 테스트에서 배포로 스스로 이어갑니다. 제가 하는 일은 무엇을 만들지 정하고 결과를 판정하는 것입니다.

Features

주요 기능

01
NAVI 분석

공고를 열면 참가자격, 예상 낙찰가, 경쟁 예상이 원문 근거와 함께 한 화면에 나옵니다. NAVI는 Notice Analytics with Verified Insights의 약자입니다.

02
근거 공개 원칙

예측치에 사용한 과거 개찰 사례를 공고 번호와 금액까지 그대로 노출합니다. 블랙박스 점수를 주지 않는 것이 제품 원칙입니다.

03
정정공고 변경 확인

마감일, 참가 자격, 예정 가격의 변경을 원본과 대조해 표시합니다. 조용히 바뀌는 조건 때문에 준비가 무산되는 사고를 막습니다.

04
낙찰 통계와 업종 분석

낙찰하한선, 적격심사 배점, 재입찰 패턴을 업종 단위로 정리해 가격 전략의 기준선을 제공합니다.

05
AI 브리프

Vercel AI Gateway 기반으로 공고문 요약과 쟁점 추출을 수행하고, 게이트웨이 미설정 시 규칙 기반으로 폴백해 서비스 연속성을 유지합니다.

06
Agentic 개발 루프

기획, 설계, 구현, 검증, 배포, 업데이트를 에이전트가 이어서 수행합니다. Playwright 실행 스펙이 검증 게이트 역할을 해, 통과하지 못한 변경은 배포 단계로 넘어가지 않습니다.

Process

서비스 파이프라인

01수집

나라장터 공고와 개찰 결과를 실시간 수집해 정규화합니다. 누적 공고 188만건, 개찰 결과 33만건 규모입니다.

02분석

참가자격 조항을 파싱하고, 유사 공고의 개찰 이력에서 예상 낙찰가와 경쟁 규모를 산출합니다. 산출 근거가 되는 사례를 함께 보관합니다.

03제시

공고 상세 화면에서 분석 결과와 원문 근거를 나란히 배치합니다. 사용자가 근거를 눌러 원문으로 바로 이동할 수 있습니다.

04추적

관심 공고의 정정 사항을 감지해 변경된 항목만 골라 알립니다.
